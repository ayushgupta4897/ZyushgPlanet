## 3. The search algorithm as implemented [verified against code at pinned commits]

### 3.1 Lineage
`pilot.py:19-24` imports `run_search as R` (`evidence/codex/run_search.py`) and monkey-patches `fastbls.seasons` so blocks split at gaps > 20 d and are capped at 90 d (each Kepler quarter becomes one semicoherent block). `run_search.py:12-16` imports `lcsearch as L` (Paras: cleaning) and `search as E` + `fastbls.seasons` (eumemic: period search). Pins in `evidence/codex/bootstrap.sh`: paraschopra `74d5624f25391f459864fdeb4027d682b7c930a3`, eumemic `2cf0b116e08c3f692febc4a447cc8ad9ebe0713d`; both MIT.

### 3.2 Holdout split (before any search)
`pilot.py:79`: `qs = sorted(unique(sector)); hold = qs[-max(2, ceil(0.25*len(qs))):]`; written to `manifests/<id>_split.json` (`:80`) before searching. Candidate: 13 quarters -> hold Q12, Q14, Q15, Q16; discovery Q1-4, 6-8, 10-11. Inversion (`:82-83`): `flux -> 2 - flux` on PSF flux, raw flux and SAP flux — the SAP line is a later repair; the original inverted pilot left SAP un-negated (`AUDIT_NOTES.txt:12`, `codex/README.md:97-100`), harmless because no inverted run reached the SAP branch.

### 3.3 Detrending (`paras lcsearch.py:59-78`, called `R.L.clean(subset, window=1.)` at `pilot.py:84`)
Per quarter `wotan.flatten(method='biweight', window_length=1.0, break_tolerance=0.5, edge_cutoff=0.0)` (Paras's TESS default 0.75 d; his comment records injection recovery 3/16, 10/16, 8/16, 5/16 for windows 0.5/0.75/1.0/1.5 d). Clip residuals > +3 sigma (flares) and < -10 sigma (dropouts) using robust std = 1.4826 MAD; per-quarter `flux_err` = that robust std. No binning for Kepler (`bin_lc` only in the TESS wrapper, 600/300 s). Discovery and holdout cleaned separately. **Caveat (added):** because clipping is asymmetric and happens after inversion, the inverted control sees flares as un-clipped dips while real data has them removed; the null is therefore not exactly matched for flaring M dwarfs (`SEARCH_AUDIT.md:31`, `improvements/README.md` item 4).

### 3.4 Period search (`eumemic search.py`)
- Inputs: `y = flux - 1`, errors from cleaning, assumed density rho = 5 solar (`pilot.py:88,90`; "merely a duration-grid prior", `AUDIT_NOTES.txt:11`), pmin 0.5 d, pmax 25 d, `k_peaks=40`.
- `expected_duration(P, rho)` (`:41-45`): a/R* = (G rho P^2/(4 pi^2))^(1/3)/R_sun[AU], G = 2.959122e-4 AU^3 Msun^-1 d^-2; duration = P/pi asin(1/a). Reproduced: P = 13.769 d, rho = 5 -> a/R* 41.3, 2.54 h; with TIC density 3.87 -> 38.0, 2.77 h.
- Stage 1 (`:194-211`; `fastbls.semicoherent`): period grid `period_grid(span_season (>=10 d, here ~90 d), rho, pmin, pmax, oversample=1.5)` with step df = 0.5*dur(P)*f/(span*oversample) (`:155-167`); 8 log-spaced durations in `[max(0.4 dur(pmin), 0.5 h), min(1.6 dur(pmax), 8 h)]`; phase-bin width = min duration/3; per block, best dips-only box delta-chi^2 per (frequency, duration), summed over blocks; durations kept only within 0.3-2.0 x expected; statistic = max over duration; `sde()` (`:285-299`) = excess over running median / MAD in 200 log-period bins.
- Peak picking (`:212-215`): local maxima ranked by excess over running median (top 40) union raw value (top 20).
- Stage 2 (`:217-228`; `fastbls.coherent`): refine each peak over all discovery data within +-1 coarse step at step scaled by span_season/span_total.
- `refine()` (`:262-274`): astropy `BoxLeastSquares.power(periods, durs, objective='likelihood', method='fast', oversample=10)` over 241 periods spanning +-3 coarse steps and 12 durations in `[max(0.3 D, 0.4 h), min(2 D, 0.3 P, 10 h)]`; returns `(P, t0, dur, depth, snr = sqrt(2*max power))`. This is the "26.7 BLS SNR".
- `event_stats()` (`:302-349`): per-event depth = weighted out-of-transit mean (|phase| > dur) minus in-transit weighted mean (|phase| < 0.5 dur); inverse-variance combined depth and `snr`; `n_good_events` = events with >= 50% cadence coverage; `odd_even_sigma`; secondary at phase 0.5 (needs > 3 points); `max_ses_frac` = max event SNR / quadrature sum of positive event SNRs; `frac_neg_events`. Run on discovery (`st`) and on the cleaned holdout at the frozen ephemeris (`ht`) (`pilot.py:91`).
- Up to two peaks per star (`pilot.py:86-101`): after rank 1, cadences within +-dur of the ephemeris are masked; stop if `snr < 9`.
- Runtime: `pilot.log` 64 stars, 9.3-35.4 s each, median 18.7 s, single-threaded (`OMP_NUM_THREADS=1`), `--workers 5`; extension 1,672 stars at 2 workers (~9 CPU-hours total).

### 3.5 First screen (`pilot.py:92`)
`snr >= 9 and st.n_good_events >= 3 and ht.n_good_events >= 3 and ht.snr >= 4 and st.odd_even_sigma < 3 and |st.secondary/st.secondary_err| < 3 and st.max_ses_frac < 0.5`. (TESS wrapper: `snr >= 8`, holdout good events >= 2, holdout snr >= 3, `max_ses_frac < 0.65`, loop stops at snr < 7.5: `run_search.py:62,64`.)

### 3.6 Automatic second-stage vet on every pass (`pilot.py:94-98`)
`independent_vet.vet(raw, P, t0, dur, holdout, controls=24, holdout_was_unseen=True)` (`evidence/codex/improvements/independent_vet.py:127-172`) on raw quarter-normalised PSF flux: per event, exposure-integrated box + intercept + slope in a window `min(max(3 dur, 0.15 d), 0.23 P)` (`:50`), split by quarter, requiring >= 2 in-transit points and >= 4 on each side (`:70`); noise floor = MAD of out-of-transit differences / sqrt 2 with chi^2 inflation (`:74-92`); combined error = max(white, cluster-robust between-event scatter) (`:99-108`); leave-one-event-out SNR, max positive-event contribution, odd/even, phase-0.5 secondary, 24 off-phase control windows avoiding |phase| < max(0.06, 2 dur/P) of primary and secondary (`:137-146`), per-quarter depths, fixed-ephemeris holdout. Flags (`:157-165`): `fewer_than_three_usable_events`, `single_event_dominance` (> 0.5), `weak_local_depth` (< 5), `odd_even_discrepancy` (> 3), `secondary_dimming` (> 3), `weak_fixed_ephemeris_holdout` (< 3). The same vetter is run on `SAP_FLUX` (`pilot.py:97-98`); bug: it inherited PSF `FLUX_ERR`, corrected in `audit_kbonus_candidate.py` by reading `SAP_FLUX_ERR` (`AUDIT_NOTES.txt:9`).

### 6.3 What the inverted comparison implies
Across 1,736 matched searches the first screen passed real data 31 times and inverted data 32 times, so at survey level the screen has no discriminating power; ~1.8% of stars pass in either polarity. At the candidate's strength two inverted stars survive, so "SNR 26.7 / holdout 15.5" is what the strongest false alarm in a ~1,700-star M-dwarf sample looks like. Kuber's corrected wording: the 2/1,736 count "is descriptive, not a calibrated false-alarm probability" because thresholds were chosen after seeing the candidate and inversion "is not established as a representative null for every systematic" (`SCIENCE.md:60-65`, `editorial-audit-20261013/README.md:39`). Added caveats: (i) the asymmetric +3/-10 sigma clipping means the inverted null is not exactly matched (flares); (ii) the two inverted survivors were never characterised; (iii) the pool is mostly G > 17, so the null rate is dominated by faint, noisy stars. The case therefore rests on post-detection vetting (U-shape, density 4.4 rho_sun consistent with the M dwarf, 13/13 localisation, dilution pattern, neighbour null, Kepler-169 timing), not on detection strength.

## 7. What went wrong or was weak, and lessons recorded

1. **Public overclaim before vetting.** Tweet "Found a new planet" at 11:12 UTC 11 Oct; TRICERATOPS/centroid/dilution tests landed 21:04 IST the same day. Repo: "No confirmed planet is claimed" (`README.md:9`); manuscript abstract: "the candidate is not statistically validated".
2. **Method-dependent depth.** PSF 1,830-2,430 ppm; SAP 1,438; model k^2 2,117 (+361/-190); holdout 1,929 vs discovery 2,268 (expected regression to the mean). Radius spans 2.5-3.1 R_earth. Root causes: 30-min cadence vs 2.1-2.4 h transit, G 16.3 star (~1,000 ppm per-point rms), aperture dominated by a 2.1x brighter neighbour.
3. **FPP 6.9% vs threshold 1.5%**, dominated by STP (planet on an unresolved bound companion). TRICERATOPS 1.1 ignores RUWE unless a `molusc_file` is passed; NFPP = 0 is bookkeeping; even a hypothetical Keck K-band curve only reaches 0.027 because companions inside ~0.1" (~30 au) remain allowed (`SCIENCE.md:82-91`).
4. **No high-resolution imaging exists** (CFHT saturated; Keck NIRC2 frames cover Kepler-169 only; Robo-AO/Gemini empty). The 2027A NASA-Keck call closed 10 Sep 2026 and requires a US-institution PI (verified).
5. **TESS cannot test it.** Aperture folds -483 to -2,075 ppm, TGLC +450 +/- 1,793; a 2,400 ppm dip would appear as ~987 ppm against 1,294 ppm scatter. The audit answers the editor's TESS question but concedes no calibrated completeness exists.
6. **Prior-search status unresolved (Barber et al. 2022).** Kepler flag Y means THYME's Notch search had a light curve for this Gaia source; which light curve (probably the KIC 5689116 PDCSAP) is unknown; resolving it needs a provenance question to the THYME authors.
7. **RNAAS declined within hours.** The note met the format (1,196 words, 124-word abstract, one figure; RNAAS allows 1,500 words total incl. abstract, one figure or table, editor-moderated, not peer reviewed). The decision letter is not public; the topics his public audit addresses are sample construction, other search outcomes/null counts, TESS non-detection and the Barber reference.
8. **Pipeline bugs found and fixed.** SAP vet inherited PSF errors; inverted pilot did not negate SAP; QLP parser dropped sectors with NaN `DET_FLUX_ERR`; QLP S99-104 barycentric timing bug affected 44/175 TESS stars (88 reruns; `TIMING_REANALYSIS.md`); Gaia IDs stored as floats; TESS speed patch silently reduced sensitivity.
9. **Post-hoc screens** (12.5-14.5 d exclusion; SNR >= 26.7 / holdout >= 15.5) repeatedly labelled "descriptive".
10. **Null calibration incomplete**: 31 vs 32; inverted survivors never characterised; no injection-recovery; asymmetric clipping; SAP branch of inverted runs never executed.
11. **Novelty logic**: KOI/TCE absence is trivially expected for a non-target; the relevant checks are the Kepler Bonus team's own lists, Bienias & Szabo 2025 (A&A 694, A209; 7 hot-Jupiter candidates), APEXBA 2022, THYME (unresolved).
12. **Reproducibility**: hard-coded `/root/ph/...` paths; three Python environments (3.10 unpinned, 3.12 lock, 3.13); "a full end-to-end rerun has not been performed here" (`README.md`); TESS lane counts self-reported.
13. **Data quirks**: KBONUS `CENTROID_*` show no transit response; Q1 only 2 events; 1,736 searches = 1,648 unique KICs; SAP depth varies with spacecraft orientation (season).
14. **Kepler-169 proximity** (4.389', 13.76710 vs 13.76945 d) killed by timing (0 overlaps for e, 67.3 h minimum, 32.8 sigma) and folded depth tests; b/d chance overlaps (5/1) at expected rate.
15. **Missing systematics test**: no comparison of in-transit cadences with quality-flag/momentum-dump cadences or rolling-band seasons (only `SAP_QUALITY == 0` filtering).

Lessons stated in Kuber's documents: "Search noise can look persuasive, too" and "Detection alone is insufficient" (website); "Do not infer novelty from catalog absence" and "A test listed in the vetting plan is not evidence of completion" (`planethunt.md`); "Treat SDE and local depth/error as ranking diagnostics ... Calibrate the entire frozen search/selection pipeline using repeated block-preserving null surveys" (`improvements/README.md` item 6); "Selecting on heldout SNR makes the holdout part of final screening ... Subsequent parameter tuning on observed holdout outcomes invalidates the original blind-test interpretation" (`SEARCH_AUDIT.md:33`); "Changing parser, clipping, duration grid, input products, or splitting logic requires explicit versioned outputs or invalidation" (`:34`); "Preserve artifacts and provenance before any rerun, and write new results to a separate dated directory" (`planethunt.md`); "Independent products from the same TESS exposures are reductions of shared data, not independent observations" (`improvements/README.md` item 7). Paras's `docs/GUIDE.md` adds the Codex-review mistakes: noise slightly underestimated (8.2 -> 7.2/7.7 sigma), missing Jacobian, a pixel test that located brightenings as easily as dimmings, 38 scrambles cannot support a tail extrapolation.
