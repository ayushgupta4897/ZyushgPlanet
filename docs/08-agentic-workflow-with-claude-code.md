## 0. TL;DR

- All three October-2026 projects converged on one skeleton: frozen target list -> per-star download with hash manifests -> BLS with a pre-split holdout -> matched inverted (and scrambled) nulls on every star -> per-star JSON results -> triage -> vetting ladder ending in TRICERATOPS -> public evidence pack. Kuber's `evidence/codex/` is the best worked example of provenance; eumemic's `pipeline/dag` is the best example of *enforced* reproducibility; Chopra's two read-only adversarial audits (Codex + a fresh Claude session) are the best example of a second agent catching real bugs.
- What went wrong was never the search code. It was claims outrunning evidence (tweet "Found a new planet" vs repo "No confirmed planet is claimed"), method-dependent numbers quoted without the method (depth 1438 / 2165 / 2348 ppm; "1830-2430 ppm across methods"), thresholds tuned after looking (Kuber: "chosen after seeing the earlier batch"; Chopra: hold-out box width changed after one fold failed), descriptive counts promoted to probabilities (Kuber's 2/1,736 "FAP", corrected 13 Oct; Chopra's withdrawn 0.01/0.2), and a manuscript submitted three days after first light, declined the same day.
- A cautionary detail the brief previously missed: Kuber's Kepler Bonus `pilot.py`, the script that found KIC 5689121, re-uses any existing result JSON with no status/version/hash check (`if dest.exists(): return json.loads(...)`); only his TESS wrapper `run_search.py` has the proper `status=='ok' and pipeline_version==3 and input_sha256==...` guard. Copy the guard, not the pilot.
- For Claude Code specifically: put the science rules in `CLAUDE.md` (docs: "target under 200 lines") and `.claude/rules/`; enforce the ones that matter with **permission deny rules first** (`Read(./runs/*/holdout/**)`, `Edit(./pipeline/params.toml)`), a `PreToolUse` hook second (docs: "PreToolUse hook decisions don't bypass permission rules"; the `if` filter is "best-effort"), and accept that neither stops a Python script from opening a file (sandboxing does). Make `/vet-candidate` a skill with a fixed ladder; make the red team a `.claude/agents/red-team.md` subagent without Edit/Write; orchestrate with a saved Workflow whose agents only *run* `python -m pipeline.*`; keep heavy compute in background Python with per-star checkpoints keyed on input SHA-256 + code hash; babysit with a Routine (min interval 1 h, Custom network allowlist including `*.stsci.edu`).
- Compute is small until you go all-sky: Kuber's saved JSONs give a median 16.0 s per Kepler Bonus star (0.5-25 d, two peaks) and 6.1 s per TESS star; 1,800 stars x 2 polarities is ~16 CPU-h. A 64-vCPU VM is ~$2.25-2.87/h on-demand; spot was $0.71 (c8g.16xlarge) to $1.16 (c6i.16xlarge) on 2026-10-17 and moves daily.

### 2.1 `CLAUDE.md` (draft at `drafts/CLAUDE.md`, 62 lines)

The draft's eleven hard rules stand (never execute/import untrusted code; sealed holdout; thresholds only in `params.toml` copied into `prereg.yaml`; matched nulls in the same invocation with a mandatory real/null pass table; empirical noise; candidate vocabulary; every number traces to a JSON via `claim-sources.json`; sidecars and `SHA256SUMS`; catalogue absence is not novelty; method-tagged depths; human signs before anything leaves the repo). Two edits: rule 1 should say the untrusted clones live outside the repo; the preamble "a PreToolUse hook enforces 1, 2 and 6" should read "permission deny rules plus a PreToolUse hook *guard* 1, 2 and 6; none of them is a security boundary".

Why the split **[doc]**: memory docs: "Claude treats them as context, not enforced configuration. To block an action regardless of what Claude decides, use a PreToolUse hook instead"; "target under 200 lines per CLAUDE.md file"; "Rules without `paths` frontmatter are loaded at launch with the same priority as `.claude/CLAUDE.md`"; "A path-scoped rule loads when Claude uses the Read, Write, or Edit tool on a matching file" (also `cat`/`head` of a single file). ### 2.2 Enforcement: permission rules first, hook second **[doc + run]**

Precedence (permissions page): "PreToolUse hook decisions don't bypass permission rules. Claude Code evaluates deny and ask rules regardless of what a PreToolUse hook returns"; "A blocking hook also takes precedence over allow rules." Rule facts that shape the config:
- Read/Edit rules use gitignore syntax: `Read(./runs/*/holdout/**)`, `Edit(./pipeline/params.toml)`, `Edit(./runs/*/prereg.yaml)`. As deny rules a single-segment directory pattern matches at any depth. They "apply to Claude's built-in file tools, to file commands Claude Code recognizes in Bash, such as `cat`, `head`, `tail`, `sed`, and `tee`, and to the targets of Bash redirections ... They don't apply to ... arbitrary subprocesses that read or write files indirectly, like a Python or Node script that opens files itself. For OS-level enforcement ... enable the sandbox."
- `Write(path)`, `Glob(path)`, `NotebookEdit(path)` rules are never consulted: "Use `Edit(docs/**)` in place of `Write(docs/**)`" (v2.1.210+). The draft's `Edit(./third_party/untrusted/**)` and `Edit(./runs/*/prereg.yaml)` denies are therefore the right form.
- Bash rules match each subcommand after splitting on `&& || ; | |& &`; deny/ask rules "apply when any subcommand matches ... even in auto mode", but "a deny or ask rule covers the invocation Claude usually produces and isn't a security boundary around the program" (a program invoked by path or inside `sh -c` escapes). `Bash(curl * -X POST *zenodo.org*)` only blocks that spelling; Python `requests` is invisible. Real protection: never give the agent the Zenodo token (keep it in a file covered by `Read(~/.config/zenodo/**)` deny) and let the human publish.
- Hooks: PreToolUse stdin has `session_id, cwd, scratchpad_dir, permission_mode, hook_event_name, tool_name, tool_input, tool_use_id`; for Write/Edit/Read `tool_input.file_path` "is always absolute" (so the draft's `case "$P" in *candidates/*/report.md)` globs still match); deny by printing `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"..."}}` and exiting 0, or exit 2 with stderr; `${CLAUDE_PROJECT_DIR}` is "the project root where the session started"; matcher `Bash|Edit|Write` is an exact-name list; hooks never fire for @-mentioned files ("no PreToolUse hook fires for them, including hooks matching `Read`" -- the docs' fix is "add a `Read` deny rule"); hook `timeout` default is 600 s for `command` hooks, so the draft's `SessionStart ... ## 3. Long-running compute

### 3.1 Inside a Claude Code session **[doc]**

- Background Bash: `run_in_background: true`; foreground default 2 min / ceiling 10 min (`BASH_DEFAULT_TIMEOUT_MS`, `BASH_MAX_TIMEOUT_MS`); "A local session you work in from a terminal ... has no time limit on background commands"; unattended sessions (`-p`, SDK, CI, cloud): 30 min default, up to 2 h via `timeout`, raise with `BASH_DEFAULT_TIMEOUT_MS > 1800000` / `BASH_MAX_TIMEOUT_MS > 7200000`; **in a `-p` run whose prompt is passed as text both defaults are 10 minutes**, and the run waits at most 10 idle minutes for background work (`CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`, `0` = no cap) unless a main-conversation background command is still running; a foreground command that hits its timeout is "moved to the background" and gets 30 min (10 in text `-p`); `/tasks` lists/stops; "Background Bash and monitor tasks are never restored on resume"; `CLAUDE_CODE_TOOL_MEMORY_LIMIT=8G` caps Bash/Monitor memory (v2.1.233+).
- Pattern that survives all of this (Kuber's `run_search.py`, not his `pilot.py`): `nohup python -m pipeline.search ... > runs/<id>/logs/search-<batch>.log 2>&1 &`, one JSON per star per polarity, skip when `status=='ok'` and `code_sha256` and `params_sha256` and `input_sha256` match (hash the code and params, not an integer version -- SEARCH_AUDIT.md's own limitation), atomic writes (`.tmp` then `os.replace`), a `_batch-summary-N.json` and a `heartbeat.json` (eumemic) so a watcher can tell stalled from slow.
- Monitor tool: "Runs a command in the background and feeds each output line back to Claude"; "Every watch Claude starts has a deadline: 5 minutes by default, at most 30 minutes, and at most 10 minutes in a non-interactive run given a single prompt with -p."
- `/loop 10m ...`: session-scoped, minimum 1 minute, 7-day expiry, fires only while the session is open and idle, recurring tasks run up to 30 min late by design (jitter). Use Monitor for babysitting; use a Routine for anything that must outlive the terminal.

## 4. Guardrails against self-deception and agent hallucination

1. **Pre-registration** (`runs/<id>/prereg.yaml`, tagged, Zenodo-deposited); the sample stage refuses to run if the prereg hash in `manifest.json` differs.
2. **Blind holdout**: last `max(2, ceil(0.25 N))` quarters (Kepler) or the latest season separated by >20 d gaps (TESS); `runs/<id>/STATE` says `phase: discovery` until `pipeline.holdout` flips it; `Read(./runs/*/holdout/**)` deny rule plus the hook; evaluated **once** at the frozen ephemeris; any second look is labelled `retrospective: true` (Kuber's `holdout_was_unseen` flag; Chopra: "only future TESS data are a truly blind test").
3. **Nulls by default**: `pipeline.search --with-nulls inverted,scramble` is the only entry point; triage JSON must contain `real_pass`, `null_pass`, `scrambled_pass`; a report without the table fails `claims check`. Counts are counts (Kuber's 2/1,736 correction); a FAP needs hundreds of full-pipeline null surveys (Chopra withdrew 0.01/0.2 from 38 scrambles). Kuber's own first screen passed noise as often as data (31/29 real vs 32/28 inverted over 1,736 stars).
4. **No post-hoc thresholds**: thresholds only in `params.toml` (hashed into `runs/<id>/manifest.json`); `Edit(./pipeline/params.toml)` deny while runs exist; a change is a new run-id plus a `docs/decisions/` entry; the prompts say in words "Never adjust thresholds" and "null_pass >= real_pass is a result, not a bug".
5. **Empirical noise**: depth error from >=40 random off-phase boxes processed identically to the transit box (Chopra) and from event-to-event scatter (Kuber: 11-22 sigma empirical vs 43 sigma formal). State which statistic is quoted (eumemic `refine` BLS SNR, astropy `BoxLeastSquares` `depth_snr`, TLS SDE are not interchangeable).
6. **Independent re-implementation**: `.claude/agents/reimplementer.md` re-derives P, T0, depth, duration from the raw FITS into `candidates/<id>/independent/` without reading `pipeline/`; `claims check` requires agreement within tolerance.
7. **Every number traces to a file**: `pipeline/claims.py build` writes `claim-sources.json`; `check` fails on any numeral in `report.md` not found (within rounding) in a cited JSON field.
8. **Novelty with snapshots**: NASA TAP tables (verified live **[run]**: `pscomppars`, `ps`, `toi`, `cumulative`, `q1_q17_dr25_koi`, `q1_q17_dr25_sup_koi`, `q1_q17_dr25_tce`, `k2pandc`, `keplerstellar`, `q1_q17_dr25_ks`, `keplernames`, `k2names`; `fpwg` and `koi` are **not** TAP tables), ExoFOP `https://exofop.ipac.caltech.edu/tess/download_toi.php?sort=toi&output=csv` and `download_ctoi.php?sort=ctoi&output=csv` **[run]**, SPOC TCE bulk files, Kepler/TESS EB catalogues, ADS/arXiv by identifier and period; harmonics 1/3, 1/2, 2/3, 3/2, 2, 3; 2.5' cone; store `{url, utc, status, sha256}` per query including failures (Kuber's `provenance.json`); emit only "not present in X as of <UTC>"; re-run on the day of any public statement.
9. **Red team before any public claim**: three skeptics (systematics / astrophysical false positive / statistics + provenance), default refuted, majority rules; reports committed under `candidates/<id>/redteam/`; author answers each finding in writing (Chopra's F1-F8 format).
10. **Human reviews raw plots**: the release skill refuses to draft a tweet/email/manuscript unless `docs/decisions/<date>-<id>-release.md` contains "I opened candidates/<id>/figures/*.png myself on <date>".
11. **Untrusted code is data**: clones stay outside the working tree; never `--add-dir` them; re-implement, cite, keep MIT texts in `third_party/LICENSES/`.
12. **Vocabulary hook**: `Write`/`Edit` of "found a (new) planet", "new planet", "discovered", "confirmed planet", "new world" into `candidates/**/report.md` or `docs/public/**` is denied.
