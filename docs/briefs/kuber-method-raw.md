## 3. The search algorithm, as implemented

### 3.1 Code lineage

`pilot.py:19-24` imports `run_search as R` (Codex's TESS wrapper, `evidence/codex/run_search.py`) and monkey-patches `fastbls.seasons` so that "seasons" are split at gaps > 20 d and capped at 90 d (`short_blocks`), i.e. each Kepler quarter is one semicoherent block. `run_search.py:12-16` in turn imports `lcsearch as L` from `paras/pipeline/lcsearch.py` (cleaning) and `search as E` plus `fastbls.seasons` from `eumemic/pipeline/` (period search). Pinned commits in `evidence/codex/bootstrap.sh:5-8`: paraschopra `74d5624f...`, eumemic `2cf0b116...`. Both MIT.

### 3.2 Holdout split (before any search)

`pilot.py:79`: `qs = sorted(unique(sector)); hold = qs[-max(2, ceil(0.25*len(qs))):]`. For 13 quarters -> 4 reserved: Q12, Q14, Q15, Q16; discovery Q1-4, 6-8, 10-11 (`manifests/2103792461826460288_split.json`). The split manifest is written before the search. Inversion (`pilot.py:82-83`): `flux -> 2 - flux` on PSF flux, raw flux and SAP flux (the SAP line was a later repair; the original inverted pilot left SAP un-negated, `AUDIT_NOTES.txt:11`, `evidence/codex/README.md:97-100`).

### 3.3 Detrending (`paras/pipeline/lcsearch.py:59-78`, called as `R.L.clean(subset, window=1.)` at `pilot.py:84`)

- Per quarter: `wotan.flatten(method='biweight', window_length=1.0 d, break_tolerance=0.5, edge_cutoff=0.0)` (Paras's TESS default is 0.75 d; Codex widened to 1.0 d for Kepler).
- Clip upward outliers > 3 sigma (flares) and downward < -10 sigma (dropouts) using the robust std of the flattened quarter; per-quarter `flux_err` = robust std (`1.4826*MAD`). No binning in the Kepler pilot (30-min cadence; `bin_lc` is only used in the TESS wrapper, `run_search.py:44-45`, 600 s or 300 s).
- Discovery and holdout subsets are cleaned separately so no holdout cadence influences the discovery trend (`pilot.py:84`; `SEARCH_AUDIT.md:7`).

### 3.4 Period search (`eumemic/pipeline/search.py`, via `R.E.semicoherent_peak` and `R.E.refine`)

- Inputs: `y = flux - 1`, errors from cleaning, assumed stellar density `rho = 5` solar (`pilot.py:88,90`; audit: "merely a duration-grid prior, not a stellar measurement", `AUDIT_NOTES.txt:10`), `pmin = 0.5 d`, `pmax = 25 d`, `k_peaks = 40`.
- `expected_duration(P, rho)` (`search.py:41-45`): circular central duration from `a/R* = (G rho P^2/(4 pi^2))^(1/3)/R_sun[AU]`. For P = 13.77 d, rho = 5: a/R* ~ 41, duration ~ 2.5 h.
- Stage 1, semicoherent (`search.py:194-211`, `fastbls.py:12-59,131-140`): frequency grid `period_grid(span_season≈90 d, rho, pmin, pmax, oversample=1.5)` (step chosen so accumulated timing error over one quarter stays below half the expected duration, `search.py:155-167`); 8 log-spaced durations between `max(0.4*dur(pmin), 0.5 h)` and `min(1.6*dur(pmax), 8 h)`; phase bin width = shortest duration / 3; for each quarter, phase-fold and compute the best (dips only) box delta-chi^2 `d^2/(1/w_in + 1/w_out)` per (frequency, duration); sum over quarters. Only durations within 0.3-2.0 x expected are kept; statistic = max over duration.
- Peak picking (`search.py:212-215`): local maxima ranked by excess over a running median in log period (top 40) union raw value (top 20).
- Stage 2, coherent refinement of each peak over all discovery data (`search.py:217-229`, `fastbls._coherent_best`): frequency window +-1 coarse step at a step scaled by season/total span; returns best delta-chi^2 and period.
- `refine()` (`search.py:262-274`): astropy `BoxLeastSquares.power(periods, durs, objective='likelihood', method='fast', oversample=10)` over +-3 coarse steps (241 periods) and 12 durations in `[max(0.3 D, 0.4 h), min(2 D, 0.3 P, 10 h)]`; returns `(P, t0, duration, depth, snr = sqrt(2*max power))`. This `bls_snr` is the "26.7 BLS SNR".
- `event_stats()` (`search.py:302-349`): per-event depth = out-of-transit weighted mean minus in-transit weighted mean (`intr: |phase| < 0.5 dur`, baseline from `|phase| > dur`), inverse-variance combined depth and `snr = depth/depth_err`; `n_good_events` = events with >= 50% cadence coverage; `odd_even_sigma`; secondary at phase 0.5 with error; `max_ses_frac` = largest single-event SNR / quadrature total; `frac_neg_events`. Applied to discovery (`st`) and, at the frozen ephemeris, to the cleaned holdout (`ht`) (`pilot.py:91`).
- Up to two peaks per star (`pilot.py:86-101`): after rank 1, cadences within +-dur of the ephemeris are masked and the search repeats; stop if `snr < 9`.
- Runtime (`pilot.log` `seconds` field): 9-35 s per star; 64 stars with `--workers 5`; extension 1,672 stars at 2 workers (hours).

### 3.5 First screen (`pilot.py:92`)

`passed = snr >= 9 and st.n_good_events >= 3 and ht.n_good_events >= 3 and ht.snr >= 4 and st.odd_even_sigma < 3 and |st.secondary/st.secondary_err| < 3 and st.max_ses_frac < 0.5`.
(The TESS wrapper used `snr >= 8`, holdout good events >= 2, holdout snr >= 3, `max_ses_frac < 0.65`: `run_search.py:62`.)

### 3.6 Second-stage checks run automatically on every pass (`pilot.py:94-98`)

- `independent_vet(raw, P, t0, dur, holdout, controls=24, holdout_was_unseen=True)` from `evidence/codex/improvements/independent_vet.py:127-172`: on raw quarter-normalised PSF flux (not the detrended flux), fit each event with an exposure-integrated box + intercept + linear slope in a window `min(max(3 dur, 0.15 d), 0.23 P)` (`:50`), split by quarter, requiring >= 2 in-transit and >= 4 points on each side (`:70`); noise floor = MAD of out-of-transit differences / sqrt 2, chi^2-inflated errors (`:74-92`); combined depth with error = max(white, cluster-robust between-event scatter) (`:99-108`); leave-one-event-out SNR, max positive-event contribution, odd/even, phase-0.5 secondary, 24 off-phase control windows avoiding the primary/secondary (`:137-153`), per-quarter depths, and the fixed-ephemeris holdout measurement. Flags at `:157-165` (`fewer_than_three_usable_events`, `single_event_dominance`, `weak_local_depth` (<5), `odd_even_discrepancy` (>3), `secondary_dimming` (>3), `weak_fixed_ephemeris_holdout` (<3)).
- The same vetter on `SAP_FLUX` (independent extraction of the same photons; `pilot.py:96-98`). Bug: it inherited PSF `FLUX_ERR`; corrected in `database_expansion/audit_kbonus_candidate.py:23-34,83` by reading `SAP_FLUX_ERR` (`AUDIT_NOTES.txt:8-9`).

### 3.7 Null and positive controls, injection tests

- Inverted control: identical pipeline on `2 - flux` for every star (`pilot.py --inverted`; `inv.py`, `inv3.py`). Pilot: 64 inverted runs, 0 passes (`run_status.json`). Extension: see Section 6.
- Positive control, Kepler: Kepler-138 (KIC 7603200 = Gaia DR3 2102053446751282944, a KBONUS primary target) via `database_expansion/kbonus/known_control.py`; recovered Kepler-138 c at 13.7812 d (BLS SNR 85.9, holdout 57.4) and d at 23.088 d (SNR 40.0, holdout 21.3), both passing the screen (`control.log`, `known_control.json`).
- Positive control, TESS: LHS 3844 b (TIC 410153553) via `evidence/codex/known_control.py`; P = 0.4629296 d, SNR 66.4, holdout 48.1 (`positive_control.json`).
- Synthetic injection + leakage test (`evidence/codex/improvements/smoke_search.py:16-58`; results `SEARCH_AUDIT.md:11-16`): two injected box transits (2.371 d, 2.3710 d recovered, discovery stat 50.5, holdout 34.9; USP 0.3173 d, 66.9/49.2) into 3 synthetic sectors; replacing all holdout flux with pure noise left period, t0, duration, depth and BLS statistic exactly identical (no holdout leakage), holdout SNRs -0.16 and 1.33. Explicitly "strong-signal implementation checks, not a sensitivity/completeness estimate". No injection-recovery completeness grid was ever run on the Kepler Bonus sample.

### 6.3 What the inverted comparison implies

Across 1,736 matched searches the first screen passed real data 31 times and inverted data 32 times: at the survey level the screen has essentially no discriminating power, and the inverted run shows that its pass rate (~1.8% of stars) is the noise/systematics floor. At the candidate's own strength two inverted stars survive (KIC 8701308 and KIC 5283912), so "SNR 26.7 with holdout 15.5" is roughly what the strongest false alarm in a ~1,700-star sample looks like. Kuber's own corrected wording: the 2/1,736 count "is descriptive, not a calibrated false-alarm probability" because the thresholds were chosen after seeing the candidate and inversion is "not established as a representative null for every systematic" (`SCIENCE.md:60-65`, `editorial-audit-20261013/README.md:39`). The case therefore rests entirely on post-detection vetting (U-shape, density consistency, 13/13 pixel localisation, dilution pattern, neighbour null), not on detection strength. Note also that the two surviving inverted stars were never inspected for what they are (brightenings of a variable? systematics?), which would have calibrated the null further.

## 7. What went wrong or was weak, and the lessons he records

1. **Overclaiming in public vs hedging in the record.** Tweet: "Found a new planet". Repo: "No confirmed planet is claimed" (`README.md:9`), "Nothing is confirmed or validated, and novelty is provisional" (`README.md:23`). The website calls it a "well-vetted planet candidate". The manuscript's own abstract says "the candidate is not statistically validated" (`rnaas.txt:15`).
2. **Method-dependent depth.** PSF depth 1,830-2,430 ppm depending on box width and baseline window; SAP 1,438 ppm; model k^2 2,117 (+361/-190). The 2.5-3 R_earth radius spans 20%. Root cause: 30-min cadence, 2.1-2.4 h transit, faint star (G 16.3, per-point rms ~0.1%), and an aperture dominated by a 2.1x brighter neighbour.
3. **FPP 6.9%, threshold 1.5%.** Dominated by STP (planet around an unresolved bound companion). TRICERATOPS 1.1 ignores Gaia RUWE; NFPP = 0 is bookkeeping because resolved neighbours were not passed (needs a Kepler PRF/aperture flux model); even a hypothetical Keck K-band curve only reaches 0.027 because companions inside ~0.1" (~30 au) stay allowed (`SCIENCE.md:82-91`).
4. **No high-resolution imaging exists.** CFHT MegaCam r image saturates both cores; Keck NIRC2 archive frames cover Kepler-169 only; Robo-AO catalogues have no match; Gemini empty; the 2027A NASA-Keck call closed 10 Sep 2026 and needs a US PI (`FOLLOWUP_PLAN.md:57`).
5. **TESS cannot recover it.** 10 FFI sectors folded at the fixed ephemeris give -483 to -2,075 ppm in apertures and +450 +/- 1,793 ppm in TGLC; the conditional PRF injection shows a 2,400 ppm dip would appear as ~987 ppm against 1,294 ppm scatter. The editor evidently asked why TESS does not show it; the audit answers that TESS has weak rejection power but concedes no calibrated completeness exists (`editorial-audit-20261013/README.md:41-60`).
6. **Prior-search status unresolved (Barber et al. 2022).** The exact Gaia source is a MELANGE-3 candidate member with a Kepler light-curve flag Y in Table 5, meaning THYME's Notch search had a light curve for it, so "never searched" cannot be claimed; the identity of that light curve (PDCSAP of KIC 5689116?) is unknown. The draft provenance e-mail to Barber/Mann was never sent (`thyme-provenance-question.txt`).
7. **RNAAS declined within hours.** The decision letter is not in the repo ("supplied by the author in this conversation; not independently checked in the portal", `submission-record.json`). The audit's four sections reveal the concerns: (i) sample construction unclear; (ii) the other 30 real first-screen passes and the 32 inverted passes were under-reported ("The original SCIENCE.md interpretation of 2/1,736 as an empirical false-alarm rate has been corrected"); (iii) TESS non-detection; (iv) the Barber reference. Structural issues: RNAAS is editorially moderated (not peer reviewed), 1,500 words, and the note reported an unvalidated FPP-7% candidate with host ambiguity from a sole independent author with no follow-up data.
8. **Pipeline bugs found and fixed along the way.** SAP vet inherited PSF errors (`AUDIT_NOTES.txt:8`); inverted pilot did not negate SAP (`README.md:98-100`); TESS QLP parser dropped sectors with NaN `DET_FLUX_ERR` (`SEARCH_AUDIT.md:24`); QLP sectors 99-104 barycentric timing bug affected 44/175 TESS stars and forced 88 reruns (`TIMING_REANALYSIS.md`); Gaia IDs stored as floats broke the first TESS pixel run (`evidence/tess/README.md:4`); TESS speed patch (pmin 1 d, 1 signal, 1200 s bins, oversample 1.5, 5 durations) silently reduced sensitivity (`pipeline_patches.diff`).
9. **Post-hoc screens.** The 12.5-14.5 d exclusion and the SNR >= 26.7 / holdout >= 15.5 thresholds were chosen after inspecting results and are repeatedly labelled "descriptive, not a clean test" (`kbonus-extension-20261011/README.md:35,44`).
10. **Null calibration incomplete.** 31 real vs 32 inverted passes; the two strongest inverted survivors were never characterised; no injection-recovery completeness; the SAP-branch of inverted runs never executed. Kuber's statement: "the real run passed the first screen no more often than the null" (`README.md:48`).
11. **Novelty logic.** Absence from KOI/TCE is trivially expected for a star that was never a Kepler target; the relevant prior searches are the Kepler Bonus team's own, Bienias & Szabo 2025 (7 background candidates) and APEXBA 2022, which Codex did check (`build_background_prior.py`), plus THYME (unresolved).
12. **Reproducibility.** Scripts hard-code `/root/ph/...` scratch paths; three Python environments (3.10 unpinned, 3.12 lock, 3.13); "a full end-to-end rerun has not been performed here" (`README.md:35`); TESS lane counts are self-reports.
13. **Data quirks.** KBONUS `CENTROID_COLUMN/ROW` are model-derived and show no transit response (`SCIENCE.md:56-58`); Q1 contributes only 2 events; the 1,736 "searches" are 1,648 unique KICs.
14. **Kepler-169 proximity** (4.39', P 13.76710 vs 13.76945 d) is a genuine red flag that had to be killed with timing (no overlaps, 67 h minimum, 32 sigma period difference) and depth tests.

Lessons Kuber's documents state explicitly: "Search noise can look persuasive, too" and "Detection alone is insufficient" (website); "Do not infer novelty from catalog absence" and "A test listed in the vetting plan is not evidence of completion" (`planethunt.md:13,18`); "Treat SDE and local depth/error as ranking diagnostics... Calibrate the entire frozen search/selection pipeline using repeated block-preserving null surveys" (`improvements/README.md:29`); "Selecting on heldout SNR makes the holdout part of final screening... Subsequent parameter tuning on observed holdout outcomes invalidates the original blind-test interpretation" (`SEARCH_AUDIT.md:33`); "Changing parser, clipping, duration grid, input products, or splitting logic requires explicit versioned outputs or invalidation" (`SEARCH_AUDIT.md:34`); "Preserve artifacts and provenance before any rerun, and write new results to a separate dated directory" (`planethunt.md:58`); "Independent products from the same TESS exposures are reductions of shared data, not independent observations" (`improvements/README.md:30`).
