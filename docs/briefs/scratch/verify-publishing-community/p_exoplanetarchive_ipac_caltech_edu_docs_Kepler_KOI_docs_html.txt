The Kepler Project identifies these objects from the TCE list for further vetting. Some objects will be flagged as false positives. All KOI tables are displayed in a single, interactive environment with separate tabs for each table (e.g., Q1-6, Q1-8, cumulative, etc). Column selection and filtering applies to all tabs, allowing easier comparison of values across KOI tables. MCMC Posterior Chains The following files contain Markov Chain Monte Carlo (MCMC) posterior chains from fits to the KOIs. Compressed tar files are available for direct download, by wget script for the complete set (single script), or by wget script with one tar file per KOI (per object script).
