## 0. The ladder, and what "credible" actually means

The professional community uses four distinct words, and the agent's output must use them exactly:

| Level | Operational meaning | Who decides | What it takes |
|---|---|---|---|
| **TCE / signal** | A periodic dip above a detection threshold (Kepler/TESS-SPOC MES >= 7.1 with >= 2 (TESS) or >= 3 (Kepler) transits; QLP: signal-to-pink-noise and BLS significance both >= 9). Source: Guerrero et al. 2021 (arXiv:2103.12538), Thompson et al. 2018 (arXiv:1710.06758). | Your pipeline | A search |
| **Planet candidate (PC)** | Passes every "not transit-like", "stellar eclipse", "centroid offset" and "ephemeris match" test; novelty checked; no formal FPP required. Kepler KOI "CANDIDATE", TESS "PC". | Robovetter / TOI team / you | Sections 1-5 of this brief |
| **Statistically validated (VP)** | Astrophysical false-positive probability below a published threshold: vespa FPP < 1 % (Morton et al. 2016, arXiv:1605.02825), TRICERATOPS FPP < 0.015 **and** NFPP < 10^-3 (Giacalone et al. 2021, arXiv:2002.00691; Giacalone et al. 2022 used FPP < 0.01, arXiv:2201.12661), normally *with* high-resolution imaging and reconnaissance spectroscopy folded in, published in a refereed journal. The SG1 code for this is **VP ("statistically validated planet that does not have a mass measurement")** (TFOP SG1 Guidelines rev 6.4, Appendix A). | Referees + the NASA Exoplanet Archive, which then lists it as a "Published Confirmed" planet | Section 6 |
| **Confirmed (CP / P)** | Mass measured (RV, TTV) or otherwise shown to be planetary beyond statistics. SG1 code **P ("confirmed planet with a mass measurement")**; TFOPWG disposition **CP**. | Referees + Archive | Section 7 |

Two facts about the Archive that matter for wording **[run]**: (i) the Planetary Systems table `soltype` values are `Published Confirmed`, `Published Candidate`, `TESS Project Candidate`, `Kepler Project Candidate (<table>)`; there is no "validated" value. (ii) Kepler-186 f (validated by Quintana 2014 / Morton 2016, never with a mass) is `soltype = 'Published Confirmed'` with `pl_bmassprov = 'M-R relationship'`; 3,035 of the planets in `pscomppars` carry `pl_bmassprov = 'M-R relationship'` versus 2,477 `Mass` and 924 `Msini`. So the archive folds validated planets into "confirmed" once a refereed validation paper exists; its inclusion criteria page (https://exoplanetarchive.ipac.caltech.edu/docs/exoplanet_criteria.html) requires mass <= 30 M_Jup, not free-floating, "sufficient follow-up observations and validation" so that a false positive is unlikely, and peer-reviewed publication. `pl_controv_flag = 1` marks 58 planets whose status has been questioned in print.

## 1. The Kepler Robovetter: the canonical test battery (Thompson et al. 2018 DR25; Coughlin et al. 2016 DR24; Coughlin et al. 2014)

The Robovetter's decision tree (Thompson 2018, Fig. 4; arXiv:1710.06758): for each TCE, (a) is it the secondary of an earlier TCE on the same star? (b) is it transit-like (NT tests)? (c) if transit-like, is there a significant secondary (SS)? (d) in parallel, centroid offset (CO) and ephemeris match (EC). A TCE failing any test is an FP; the four major flags are exported as `koi_fpflag_nt`, `koi_fpflag_ss`, `koi_fpflag_co`, `koi_fpflag_ec` (Exoplanet Archive KOI column docs, https://exoplanetarchive.ipac.caltech.edu/docs/API_kepcandidate_columns.html). Every test is run on two detrendings (the DV fit residual "DV" and the alternative "ALT" detrending with trapezoid fits), and failure on either counts.

### 1.1 Not-transit-like (NT) tests and thresholds

| Test | Metric / definition | DR25 threshold (Thompson 2018 App. A) | Code |
|---|---|---|---|
| LPP (Locality Preserving Projections) | Fold, bin to 141 points, project to 20 dims, mean distance to 15 nearest known transits (Thompson 2015) | fail if LPP > 2.2 (DV) or > 3.2 (ALT); DR24 used median + 4.06 sigma of injected distribution (Coughlin 2016 §3.2.1.1, arXiv:1512.06149) | SourceForge (per Thompson 2018) |
| Model-shift uniqueness (MS1-MS3) | Convolve the best-fit model with the phased light curve; sigma_Pri, sigma_Sec, sigma_Ter, sigma_Pos = significance of the primary, deepest secondary, tertiary and most-positive events; F_red = red/white noise ratio at the transit duration; FA1 = sqrt(2)·erfcinv(T_dur/(P·N_TCE)), FA2 = sqrt(2)·erfcinv(T_dur/P). MS1 = FA1 − sigma_Pri/F_red; MS2 = FA2 − (sigma_Pri − sigma_Ter); MS3 = FA2 − (sigma_Pri − sigma_Pos) | fail if MS1 > 1.0, MS2 > 2.0 or MS3 > 4.0 (DV); MS1 > −3.0, MS2 > 1.0, MS3 > 1.0 (ALT) | C++11, https://github.com/JeffLCoughlin/Model-Shift (`./modshift infile outbase name period epoch 1`) |
| Marshall (per-transit shape) | Fit each event with transit, SPSD, step and constant models; event invalid when a non-transit model wins by BIC >= 10 (and non-transit BIC < 1e6 and either MES/sqrt(N_real) > 4 or the constant model wins) | TCE fails if < 3 good events remain or recomputed MES < 7.1 | Mullally et al. 2016; SourceForge |
| Skye (clustered transit times) | For TCEs with P > 45 d, bin all transit times per skygroup in 1-d bins; rate threshold R + 3·sqrt(R); transits in high bins marked bad | same individual-transit rule | https://github.com/JeffLCoughlin/skye |
| Rubble (missing cadences) | fraction of expected cadences present over 2 durations | < 0.75 marks the transit bad | — |
| Chases (competing SES peaks) | C_i = min(Δt, Δt_max)/Δt_max, Δt_max = P/10; only for TCEs with <= 5 transits; events with C_i < 0.01 excluded | TCE fails if median C < 0.8 | — |
| Zuma | any individual event with SES < 0 is bad | — | — |
| Tracker | TPS vs DV ephemeris slip > 0.5 T_dur marks event bad | — | — |
| Single-event domination | SES_max/MES | fail if > 0.8 for P > 90 d | — |
| Same period as earlier NT FP | sigma_P > 3.25 (and epochs within 2.5 durations for transit-like FPs) | fail | — |
| Gapped events | fraction of events with SES = 0 or Rubble > 0.75 | fail (TRANS_GAPPED) if gapped fraction >= 0.5 | — |
| SWEET (sinusoidal variability) | sine fits at P/2, P, 2P on the light curve | SWEET_NTL if above threshold, amplitude > depth, P < 5 d (text says 10 d; the paper itself notes the inconsistency) | — |

### 1.2 Stellar-eclipse (SS) tests

| Test | Definition | DR25 threshold |
|---|---|---|
| Significant secondary (MS4-MS6) | MS4 = sigma_Sec/F_red − FA1; MS5 = (sigma_Sec − sigma_Ter) − FA2; MS6 = (sigma_Sec − sigma_Pos) − FA2 | SS if MS4 > 1, MS5 > 0, MS6 > 0 in either detrending |
| Half-period exception | if sigma_Pri − sigma_Sec < FA2 and the secondary sits within 1/4 duration of phase 0.5 -> the "secondary" is just another primary; PC at twice the period (PLANET_PERIOD_IS_HALF) | overrides SS |
| Planet-occultation exception | geometric albedo < 1, R_p < 30 R_E, secondary depth < 10 % of primary, b < 0.95 -> PC with SS flag kept (PLANET_OCCULT) | overrides SS |
| Odd/even depth | sigma_OE = (d_odd − d_even)/sqrt(sigma_odd^2 + sigma_even^2) using points within ±30 min of mid-transit | DR25 DEPTH_ODDEVEN: sigma_OE > 1.1; model-shift odd/even MOD_ODDEVEN > 11.2 (DV) / 19.8 (ALT). DR24 used sigma_OE > 1.7 (Coughlin 2016 §3.3.3) |
| V-shape | R_p/R_* + b from the DV fit | DEEP_V_SHAPED if R_p/R_* + b > 1.04 |
| Secondary TCE | later TCE on the same star with sigma_P > 3.25 and epoch offset >= 2.5 durations | HAS_SEC_TCE / IS_SEC_TCE |
| SWEET_EB | sinusoid above threshold with amplitude < depth and P < 5 d | SS |

### 1.3 Centroid-offset (CO) tests (Mullally 2015 centroid Robovetter; Bryson et al. 2013, arXiv:1303.0052)

- Needs >= 3 quarterly difference images with a discernible stellar image (>= 3 adjacent bright pixels); otherwise CENT_FEW_DIFFS and no decision.
- **Resolved** offset: the brightest difference-image pixel lies > 1.5 px (6") from the target in >= 2/3 of quarters -> FP (CENT_RESOLVED_OFFSET).
- **Unresolved** offset: PRF-fit centroid of the difference image offset from the out-of-transit centroid at > 3 sigma **and** > 2", or > 4 sigma **and** > 1" -> FP (CENT_UNRESOLVED_OFFSET). DV computes a 3-sigma "radius of confusion" with a 0.2" floor (0.0667" quadrature term), combines quarters by inverse-variance robust mean (Twicken et al. 2018, arXiv:1803.04526 §III.4).
- Informational flags: CENT_KIC_POS (offset measured from the KIC position instead of OOT centroid — alone, no shift implied), CENT_CROWDED, CENT_SATURATED, CENT_INVERT_DIFF (star *brightens* in transit: a warning that the difference image is dominated by something else), CENT_UNCERTAIN, HALO_GHOST (DV ghost diagnostic: halo-aperture correlation with the transit model exceeds the core's — a sign of a distributed/background source; 98.1 % of golden PCs have core > halo).
- Injection calibration (Coughlin 2016 §4): off-target injections up to ~10" were recovered as offsets ~50 % of the time at 2" (0.5 px) for MES = 20. **This is the sensitivity floor of pixel vetting at Kepler's 3.98" pixels.**

### 1.4 Ephemeris match (EC): Coughlin et al. 2014 (arXiv:1401.1240) with DR25 modifications

Original statistics (Coughlin 2014): ΔP = (P_A − P_B)/P_A, ΔT = (T_A − T_B)/P_A; ΔP' = |ΔP − round(ΔP)|, ΔT' = |ΔT − round(ΔT)|; sigma = sqrt(2)·erfcinv(Δ'). A match requires **sigma_P >= 3.5 and sigma_T >= 2.0** (random pairs cluster at 0.674, 0.674), checked A->B and B->A; any integer ratio is allowed by construction (77 % of matches were 1:1, 19 % 1:2, 4 % odd ratios up to 13-15x). Spatial criteria (at least one): (a) separation < d_max = 50·sqrt(10^6·10^(−0.4 m_kep) + 1)" using the brighter star's magnitude (~50" floor for faint stars, ~500" at Kp 10, ~5000" at Kp 5); (b) antipodal about the FOV centre within 50"; (c) same module within 10 px in row or column. Mechanisms: direct PRF contamination (d < d_max), antipodal reflection off the Schmidt corrector, CCD video crosstalk (same module, different output, same row & column within 10 px; coefficients ~±1e-2), column anomaly (same module, same column within 10 px, rows differ). Direct-PRF depth model D2/D1 = 10^(−0.4Δm)/f_prf(d) + 1 with f_prf = 0.5 exp(−d²/α²) + 0.5 γ²/(d²+γ²), α = 6.73", γ = 0.406". Parent = deepest object among matches; 685 KOIs (12 %) were FPs this way, 118 found by no other method.

DR25 variant (Thompson 2018 App. A.6, text extracted from the arXiv PDF **[run]**): period/epoch differences are expressed in units of the injection-recovery-measured DV ephemeris uncertainty ("worse matches having increasingly larger values of S_P and S_T"); a match requires **S_P < 5 and S_T < 5 with period ratio <= 50**, different KIC IDs, and one of: d < 55·sqrt(10^6·10^(−0.4 m_kep)+1)"; antipodal within 100" (25 px); same module within 5 px in column; same module within 5 px in row and column. Compared against all DR25 TCEs, 8,826 KOIs, 2,605 EBWG eclipsing binaries (2016-10-13 list), Kreiner's ground-based EB ephemerides, TrES EBs and the GCVS; 1,859 TCEs flagged. "Bastards" (flag 1) are matches where neither object can be parent (depth ratio between 0.01 and 100 for column-anomaly/reflection cases; > 4 sigma outliers from the PRF depth model with α = 6.93", γ = 0.358").

### 1.5 Disposition score and code

The `koi_score` is the fraction of 10,000 Monte-Carlo re-runs (metrics perturbed by their asymmetric uncertainties) that return PC; it is a confidence in the disposition, not a planet probability (Thompson 2018 §3.2). The DR25 Robovetter itself is public C++ (`./robovet INPUTFILE OUTFILE NMC`, >= 1,000 iterations recommended; inputs for OBS/INV/SCR1-3/INJ1-3 runs shipped; https://github.com/nasa/kepler-robovetter). What to borrow for your own pipeline: the *structure* (NT -> SS -> CO -> EC), the model-shift statistics (reimplemented in LEO-Vetter and exovetter), the individual-transit culling (Rubble/Chases/Zuma/Marshall), the exception logic for occultations, and above all the use of **inverted (INV) and scrambled (SCR) runs to calibrate the vetter's false-alarm rate** — which is exactly what Kuber's and eumemic's inverted-flux controls are.

## 2. TESS vetting ecosystem and the TOI/TFOP standards

### 2.1 How a TOI is made (Guerrero et al. 2021, arXiv:2103.12538)

- SPOC: TCE if MES > 7.1 with >= 2 transits and passing transit-consistency tests; DV runs odd/even depth, weak secondary (MES_sec vs phase; if significant, albedo and T_eff of the "planet" are computed — albedo >> 1 kills the planet interpretation), ghost diagnostic (core vs halo), difference-image PRF centroids (for TESS, offsets are "significant at 3 sigma above about 7.5 arcseconds"), flux-weighted centroid motion, bootstrap FAP. QLP (FFIs): BLS, TCE if signal-to-pink-noise and BLS significance both > 9; triage cuts Tmag <= 10.5 (prime mission), R_p > 35 R_E removed, 6 % depth cut for stars without radii.
- Triage: TEC (TESS-ExoClass, https://github.com/christopherburke/TESS-ExoClass) sorts SPOC TCEs into Tier 1 (no warnings), Tier 2 (>= 1 flag, e.g. centroid), Tier 3 (probable EBs with significant secondary); AstroNet-Triage for QLP.
- Vetting in TEV: 3-5 vetters per TCE assign PC / EB / V (variability) / IS (instrument/systematic) / U; anything PC or U goes to group vetting (>= 3 vetters, ~50 TCEs per 2-h session) which checks centroid motion, aperture-dependent depth, etc., then promotes to TOI and sets TFOP priorities. TOIs update on ExoFOP twice daily; MAST archives a static monthly copy.
- Dispositions: TOI table `tfopwg_disp` in {APC = ambiguous planetary candidate, CP, FA, FP, KP, PC} (Exoplanet Archive TOI column docs, https://exoplanetarchive.ipac.caltech.edu/docs/API_TOI_columns.html).
- CTOIs: "ExoFOP emphasizes CTOIs should only be reported if there is no TOI with the same period"; the TOI team matches CTOIs to TCEs by TIC and period and may promote one "if the CTOI identifies a quality planet candidate" that SPOC/QLP rejected in triage; all 169 prime-mission promoted CTOIs were SPOC/QLP TCEs (106 recovered from triage). CTOIs with no TCE need manual reprocessing.
- Multiplicity: the TESS multi boost is ~20 for all SPOC candidates and ~54 for planets < 6 R_E (Guerrero 2021).

**Policy change you must design around:** since 2026-08-19 ExoFOP accepts community candidates (TESS, Kepler, K2 "and beyond") only after they are "published in a peer-reviewed journal with online access", and upload needs approval via the Published Candidate Upload Request form (https://exofop.ipac.caltech.edu/tess/pub_candidate_upload_request.php). The Candidate Guidelines (https://exofop.ipac.caltech.edu/tess/candidate_help.php) add: an RNAAS note is acceptable only "if the detection and vetting methods were previously published in a peer-reviewed, cited paper"; at least two of period / epoch (BJD) / depth (ppm) > 0, duration required for cTOIs; cross-check against TOIs and, if the period matches or is an integer multiple of an existing object on the same star, add a parameter set rather than a new object; name TID.nn; supply a light-curve figure; initial disposition PC or FP only (CP not allowed). Chopra's GUIDE records exactly this trap ("Since 19 August 2026, ExoFOP accepts only already-published candidates", https://github.com/paraschopra/tess-planet-candidates/blob/main/docs/GUIDE.md).

### 2.2 TFOP working groups (https://tess.mit.edu/followup/; charter v21 of 2026-07-12)

- **SG1 Seeing-limited photometry** (chair Karen Collins): confirm the event on target, find NEBs, improve ephemerides. SG1 Observation Guidelines rev 6.4 (Conti 2020, https://astrodennis.com/TFOP_SG1_Guidelines_Latest.pdf, text extracted **[run]**): check every Gaia star within **2.5'** bright enough to produce the depth (an "NEB table" marks each as cleared / not cleared), and use these codes: **NEB** (nearby EB resolved by follow-up), **BEB** (blended EB, usually from chromatic depth), **EB** (on target but too deep), **VPC** (verified on target, no contaminating Gaia star in the follow-up aperture), **VPC+** (no depth chromaticity), **VPC−** (aperture contaminated), **CPC** (too shallow for ground, but all NEB candidates cleared), **PPC** (promising: obvious NEBs cleared, not all), **PC**, **NPC** (event on a nearby star but planet-like -> new TOI), **PNEB** (possible NEB, single epoch), **STPC**, **VP** (statistically validated, no mass), **P** (confirmed with mass), **KP**, **SB1/SB2**, **FA**.
- **SG2 Reconnaissance spectroscopy** (Sam Quinn): stellar parameters, SB1/SB2 rejection, rapid rotators.
- **SG3 High-resolution imaging** (David Ciardi): AO/speckle/lucky imaging for companions unresolved by TIC/seeing-limited imaging.
- **SG4 Precise RVs** (Dave Latham): masses.
- **SG5 Space-based photometry** (Diana Dragomir): HST/Spitzer/CHEOPS/JWST ephemeris and light curves. Since 2021 Gaia also shares unpublished epoch photometry of TOIs to confirm the host.

## 3. Pixel-level and centroid vetting

### 3.1 Difference imaging (Bryson et al. 2013; Twicken et al. 2018; Guerrero 2021)

Per quarter/sector: mean in-transit image minus mean out-of-transit image (balanced before/after windows, avoiding other TCEs' transits and anomaly cadences) = an image of *what dimmed*. Fit the PRF to the difference image and to the out-of-transit image; the offset between them (and vs the catalogue position, after proper motion) locates the source. Kepler criterion: 3 sigma radius of confusion, floors 0.2"; FP if 3 sigma > 2" or 4 sigma > 1" (Section 1.3). TESS SPOC: significant if 3 sigma and > ~7.5" (Guerrero 2021). Kostov et al. 2025 (TESS Ten Thousand EB catalogue, arXiv:2506.05631) use a 0.2 px (~4") photocentre threshold with PRF + Gaussian fits averaged. LEO-Vetter: fail at > 15"; trust only prfFitQuality >= 0.3. eumemic's calibrated variant: fit per sector (up to 12), F-test of the mean offset vs the target and every star within 2' that could produce the depth, 1" per-axis scatter floor, reject at p < 0.001 — calibrated so that 0/565 known planets are rejected while 73 % of 175 neighbour-caused signals are; but only 38 % of sources within 15" are caught (https://github.com/eumemic/exoplanets validation/centroid_sectors.md). Two complementary flux-only tests: **depth vs aperture radius** (flat for on-target, growing for a neighbour; Kuber's TESS plan step 5, planethunt:evidence/tess/vetting_plan-18fa5da8.md) and the **ghost/halo diagnostic**.

### 3.2 Tools

- **KBONUS-specific "which star dims" (the Kuber approach, planethunt:analysis/validation-20261011/SCIENCE.md and scripts/kepler/)**. KBONUS gives every Gaia source in a TPF its own PSF light curve (Linearized Field Deblending; sources closer than 1" are *not* deblended — only the brighter is kept; Martínez-Palomera, Hedges & Dotson 2023, AJ 166, 265, arXiv:2310.17733; MAST HLSP https://archive.stsci.edu/hlsp/kbonus-bkg, DOI 10.17909/7jbr-w430). Three tests that share photons but not modelling: (1) **neighbour light curve at the ephemeris** — KIC 5689116's own PSF light curve shows 24 ± 41 ppm where ~1,100 ppm would be needed to host the signal; its SAP curve shows 137 ± 42 ppm, the expected leakage of the target into its aperture; (2) **dilution pattern** — per-quarter SAP depth tracks the target's share of aperture flux (FLFRCSAP × PSF/SAP): dilution model chi2 15.4/12 (p = 0.22), constant-depth p = 0.005, contaminant-hosted p ~ 1e−36; the 7-pixel-aperture seasons (Q2, Q6, Q14) have the shallowest SAP depths, the opposite of a contaminant-hosted signal; (3) **raw-TPF flux-weighted centroids** with the first-order prediction shift_j = −δ_ap·(x_j − c) for a dip on star j: target model chi2 43.9/24 (p = 0.008), neighbour rejected at Δchi2 = 934, every other Gaia source within 30" at Δchi2 >= 4,300 (`kcentroid_tpf.py`). Caveat Kuber documented: the KBONUS `CENTROID_COLUMN/ROW` columns show no in-transit response (chi2(zero) = 25.5/26) — they are model-derived and unusable for this test; the KBONUS paper itself demonstrates the neighbour-light-curve method on KOI 770.01 (true EB is a neighbour 1.36" away, 2.6 mag fainter) and KOI 909.01 (neighbour KIC 8256044 at 8"). Recommended KBONUS quality cuts: PSFFRAC > 0.5 (paper), plus Kuber's CROWDSAP > 0.7; PERTRATI ~ 1 and small PERTSTD or fall back to mean-PSF photometry.

### 3.4 The pitfall Chopra hit, and the fix

From docs/GUIDE.md (https://github.com/paraschopra/tess-planet-candidates): the first pixel test "could 'locate' a brightening as easily as a dimming, and it treated each sector separately"; a "centroid shift" turned out to be spacecraft rotation ("not real in sky coordinates"). Fix: (1) make the test sign-aware — fit the difference image for a *decrease* of flux consistent with the transit depth at each candidate source, and report the fit for the inverted light curve as a control (if "brightening at the target" is as significant, the test has no power); (2) joint fit across all sectors with each sector's own PRF/orientation; (3) balanced before/after out-of-transit frames; (4) test every Gaia/TIC neighbour as the hypothesised source with TESS-band fluxes, not just "target vs not target"; (5) work in sky coordinates (RA/Dec offsets) so roll between sectors cancels. Kuber's `CENT_INVERT_DIFF`-style sanity check is the same idea: the Robovetter flags difference images where the star brightens in transit.

## 6. Statistical validation

### 6.1 TRICERATOPS (Giacalone et al. 2021, AJ 161, 24; arXiv:2002.00691; https://github.com/stevengiacalone/triceratops)

- **Scenarios**: TP, EB, EBx2P (planet / EB / EB at twice the period on the target as a single star); PTP, PEB, PEBx2P (on the target, which is the *primary* of an unresolved bound binary that dilutes the signal); STP, SEB, SEBx2P (on the unresolved bound *secondary*); DTP, DEB, DEBx2P (on the target, diluted by an unresolved fore/background star drawn from the field population); BTP, BEB, BEBx2P (on that unresolved background star); and for each resolved nearby star NTP, NEB, NEBx2P. **FPP = 1 − (P_TP + P_PTP + P_DTP)**; **NFPP = Σ(NTP + NEB + NEBx2P)** (so NFPP is 0 whenever no neighbours are supplied — Kuber's caveat). Classification: validated if FPP < 0.015 and NFPP < 10^-3; likely planet if FPP < 0.5 and NFPP < 10^-3; likely nearby FP if NFPP > 0.1 (and the 2021 paper's note that larger-than-~8 R_E objects cannot be separated by radius; eumemic applies the thresholds only below 8 R_E).
- **Inputs**: `target(ID, sectors, search_radius=10, mission='TESS'|'Kepler'|'K2', ra, dec, verify_ssl, estimate_missing_params, background_population_source='gaia'|'trilegal')` queries the TIC (and KIC/EPIC via Vizier for Kepler/K2), builds the neighbour table (`.stars`: ID, Tmag, Jmag, Hmag, Kmag, ra, dec, mass, rad, Teff, plx, sep, PA, fluxratio, tdepth), downloads TESScut (or Kepler/K2) cutouts; `calc_depths(tdepth, all_ap_pixels, dilution_corrected=True)` computes the depth each neighbour would need (circular Gaussian PSF σ = 0.75 px; 4" Kepler, 20.25" TESS pixels); `calc_probs(time, flux_0, flux_err_0, P_orb, contrast_curve_file=None, filt='TESS', N=1e6, parallel=False, drop_scenario=[], verbose=1, flatpriors=False, exptime=0.00139, nsamples=20, molusc_file=None, dilution_corrected=True)`. `time` is days from mid-transit (folded), `flux_0` normalised to 1, `flux_err_0` a scalar. **Contrast curve** file: two columns, separation [arcsec] and Δmag; `filt` ∈ {TESS, Vis, J, H, K}; a list of files/filters is allowed and the tightest constraint wins. **molusc_file**: MOLUSC companion CSV used only by PTP/PEB/STP/SEB.
- **Oct-2026 status [run + PyPI/GitHub]**: `pip install triceratops` -> **1.1.0 (uploaded 2026-09-02)**, Python >= 3.8 to 3.13; `pytransit==2.2` pinned (predates NumPy 2 — shims in `likelihoods.py`; `setuptools<81` forced on >= 3.12; numpy < 2 and scipy < 1.14 for < 3.13 but numpy >= 2.1 for 3.13). In a fresh Python 3.13 venv, `uv pip install triceratops leo-vetter exovetter lightkurve` resolved 114 packages and imported cleanly (pkg_resources deprecation warnings only). 1.1.0 changes that matter: (a) **the light curve is now assumed dilution-corrected** (PDCSAP-like); pass `dilution_corrected=False` for raw SAP/KBONUS-SAP input or the transit is corrected twice; (b) the blended-star scenarios (DTP/DEB/BTP/BEB) now default to a **real Gaia DR3 field population** (`query_gaia_background`) because the **TRILEGAL server (stev.oapd.inaf.it) has been unreachable with SSL/connection errors**; with `background_population_source='trilegal'` and the server down, those six scenarios are *silently skipped* and FPP is returned without them (KNOWN_ISSUES.rst); Gaia is shallower in crowded/low-latitude fields (Kepler field!), biasing those terms low; (c) missing TIC mass/radius/Teff are estimated from photometry via Pecaut & Mamajek; (d) `remove_nearby_stars()`, `get_spoc_apertures()`, multiple contrast curves. Chopra's issues (old numpy/scipy pins -> separate `.venv-tri`; TRILEGAL incomplete certificate chain -> custom CA bundle; MAST stalls on large downloads) are consistent with this; the TRILEGAL path should be considered unreliable in Oct 2026.
- **Running it for a Kepler/KBONUS source without MAST (Kuber's driver, verified here)**: build the folded, per-event-baselined PSF light curve; construct `stars` by hand from TIC/Gaia values; build the field population yourself (Kuber: the 120" Gaia DR3 cone characterised with TRICERATOPS' own recipe and resampled to the 0.1 deg² the priors assume, plus a G 21-22.5 extrapolation) in the TRILEGAL schema `Mact, logg, logTe, [M/H], TESS, J, H, Ks`; then `T = object.__new__(tr.target); T.ID=…; T.mission='Kepler'; T.search_radius=10; T.sectors=np.array([1]); T.stars=stars; T.trilegal_fname=<csv>; T.trilegal_url=None; T.background_population_source='file'; T.N_pix=22; T.calc_probs(time, flux, err, P, N=1e6, exptime=1765.464/86400, nsamples=20, dilution_corrected=True)`. **[run]** with a synthetic 2,168-ppm fold and a synthetic (demo-only) 400-star field: N = 20,000 took 17 s on one CPU (so N = 1e6 ≈ 15 min), FPP 0.043, NFPP 0, STP 0.043 dominant, EB/SEB ~1e-40 — the same qualitative structure as Kuber's real result (TP 0.75, PTP 0.17, STP 0.068). Script: `scripts/triceratops_offline.py`. Kepler exposure time is 1765.464 s (KDCH §1).
- **Practice**: run >= 10-20 times with different seeds and report mean ± spread (Giacalone 2022 ran 20; eumemic 10 default + 10 Gaia-constrained; Kuber 4 + 2 + 2); use one cadence per run (eumemic: mixing 200-s and 1800-s data made FPP swing 1e-7 -> 0.5 on one target); supply resolved neighbours so NFPP is meaningful; a prior failure of the Gaia/TRILEGAL query silently removes scenarios — check `T.probs` has all 15 target rows.

- **PASTIS** (Díaz et al. 2014, MNRAS 441, 983; arXiv:1403.6725): full Bayesian modelling of light curve + RV + SED against all FP hypotheses; conclusive only for transit SNR ≳ 50; not generally distributed. Mention only.

### 6.3 MOLUSC (Wood et al. 2021; https://github.com/woodml/MOLUSC)

Monte-Carlo companions (Raghavan 2010 period/mass-ratio distributions) rejected by RV, by imaging contrast curves (`--ao file --filter J|H|K|G|R|I`), by Gaia resolution (`--gaia`) and by RUWE (`--ruwe`: companions whose photocentre wobble would exceed the measured RUWE are removed); CLI `python BinaryStarGUI.py -v [--rv f --resolution R] [--ao f --filter K] [--ruwe --gaia] [--transit] [--age Gyr] prefix RA Dec N mass`; outputs `prefix_kept.csv` (survivors) which is what TRICERATOPS' `molusc_file` consumes. eumemic's recipe (validation/gaia_companion_limits.md): MOLUSC v20220321, 200,000 companions per host, Gaia resolution + RUWE tests (RUWE test needs a 5-parameter solution and Gaia colours), BHAC15 ages adjusted for > 1.1 M_sun, TRICERATOPS then draws bound companions only from survivors with periastron > 10 au; effect: median FPP 0.045 -> 0.016 over 542 candidates; for 141 bright hosts the Gaia epoch-RV scatter σ = ε·sqrt(2N/π) vs K_min/√2 > 3σ rules out EB/EBx2P. For Kuber's star (RUWE 0.984) this is the single cheapest step that could move the STP term — he flagged it but did not run it (SCIENCE.md "Next").

### 6.4 High-resolution imaging and archival contrast curves

- Facilities and limits: Gemini-N/S 'Alopeke/Zorro speckle at 562/832 nm, ~0.02" inner working angle, 5-9 mag contrast, limiting r ≈ 18 under good conditions (Scott et al. 2021, Frontiers; Lester et al. 2021, arXiv:2106.13354); WIYN/NESSI, SOAR/HRCam, Palomar/PHARO, Shane/ShARCS, Keck/NIRC2 (NGS ≲ 13-14 mag; LGS with a tip-tilt star as faint as V = 18, per the NIRC2 AO page https://www2.keck.hawaii.edu/realpublic/inst/nirc2/nirc2_ao.html).
- Archival: for any TIC, `download_imaging.php?output=csv&target=TIC…` lists observations and `download_filelist.php?id=TIC&output=csv` lists uploaded files (contrast-curve `.txt`/`.dat` and images) which `download_files.php?id=TIC` tars up; the Stellar Companions table gives detected companions (sep, PA, Δmag). Only TOIs/CTOIs tend to have them; TIC 120686465 has none **[run]**, and the Robo-AO Kepler surveys returned nothing within 30" (Kuber). Format them as "sep(arcsec) Δmag" and pass with the right `filt`.

### 6.5 Gaia as a companion detector

- **RUWE**: > 1.4 = poor single-star fit (Lindegren 2018, cited by Stassun & Torres 2021); Penoyre et al. 2022 propose 1.25 for EDR3; Stassun & Torres 2021 (arXiv:2101.03425) show RUWE in 1.0-1.4 still tracks the photocentre semi-major axis of benchmark EBs (r² = 0.82 down to ≲ 0.1 mas), and nearly all RUWE > 1.4 EBs are known/suspected triples; Belokurov 2020 (arXiv:2003.05467) calibrates RUWE -> wobble amplitude for periods up to several years. Companions: also `astrometric_excess_noise[_sig]`, `ipd_frac_multi_peak`, `ipd_gof_harmonic_amplitude`, `duplicated_source`, `non_single_star`. Treat RUWE < 1.4 as "no evidence", never as a veto (Kuber's FOLLOWUP_PLAN).
- **NSS tables** (Section 4.1) and **vari_eclipsing_binary / vari_classifier_result (ECL, EP)** should be joined on source_id for the target and every neighbour within the aperture.
- **Gaia epoch RVs** (G_RVS ≲ 12): `radial_velocity_error`, `rv_nb_transits`, `rv_amplitude_robust`, `rv_chisq_pvalue`, `rv_renormalised_gof` flag SB1s (eumemic's recipe above); irrelevant for a G = 16 M dwarf.

### 6.6 Multiplicity boost

Lissauer et al. 2012 (arXiv:1201.5424; PDF text extracted **[run]**): the Bayesian prior for a planet is boosted by ~25 for a candidate with one additional candidate in the system and ~100 with two or more (their alternative estimate: ~30 and ~50); Rowe et al. 2014 (arXiv:1402.6534) used this to validate 851 planets at < 1 % FP; Guerrero 2021 finds ~20 / ~54 for TESS. Only applies if the second signal is itself a clean, independent candidate (no ephemeris match between them, consistent stellar density).

## 7. Candidate vs validated vs confirmed: realistic routes

**Definitions used by the Archive and journals** are in Section 0. Practically: AJ/ApJ/MNRAS/A&A accept "validation" papers when FPP is below the tool's published threshold *and* the standard follow-up has been done (Giacalone 2022: TRICERATOPS FPP < 0.01, NFPP < 10^-3, with speckle/AO imaging, recon spectroscopy, and SG1 photometry clearing stars within 2.5'); candidates can be published as candidates (RNAAS, AJ "planet candidates" papers) but ExoFOP will now ingest them only post-publication, and RNAAS counts only if the methods were previously published and cited. Kuber's RNAAS was declined the same day; his audit implies the editor's concerns were sample construction/selection, the full set of search outcomes (31 real vs 32 inverted first-screen passes over 1,736 stars, i.e. no excess over the null), the TESS non-detection, and the Barber 2022 prior-search question — none of which is a vetting failure of the candidate itself, all of which are *survey-level honesty* items the agent must produce automatically (Section 8).

**What a solo person can reach**
- *Candidate*: yes, fully — Sections 1-5 are all free archival computation; Kuber did it in days.
- *Statistically validated*: only with (a) a TRICERATOPS FPP that falls below 0.015 after real constraints and (b) a refereed paper. For a bright TESS host the constraints are Gaia (MOLUSC) + archival/newly obtained speckle + a recon spectrum — achievable with one collaborator at a 2-4 m facility or via TFOP once it is a TOI. For Kuber's star the STP term (planet around an unresolved bound companion) is what blocks validation, and only RUWE/MOLUSC, AO/speckle, multi-band depths or a resolved transit can shrink it.
- *Confirmed*: needs a mass (RV or TTVs) — essentially never solo.

**Kp 16.3 Kepler-field M dwarf (KIC 5689121-like)**: TESS cannot test it (a 2,400 ppm dip injects only ~987 ppm into a 1.5-px aperture against 1,294 ppm scatter; Kuber's PRF injection); ground photometry of a 2,000 ppm, 2.3-h event on a Kp 16.3 star with a 2x brighter neighbour 7" away needs a 1-2 m telescope in good seeing and a red filter, with both stars measured simultaneously; speckle at Gemini is marginal at r ≈ 18 limit (the star is G 16.3, so feasible but with poor contrast), Keck LGS-AO is feasible (tip-tilt star V ≤ 18 nearby; the G 15.5 neighbour may serve); recon spectroscopy of an M dwarf at V ~ 18 needs an 8-10 m telescope; precise RVs are out of reach (expected K ~ few m/s on a V ~ 18 star). Realistic ceiling: *well-vetted candidate*, possibly *validated* if AO + MOLUSC push STP below ~1 % — Kuber's hypothetical Keck curve only reached 0.027. Note also that the KBONUS catalogue is a *background* M-dwarf sample: Kepler primary targets are excluded, so the SPOC pipeline never searched these light curves, which is the real novelty argument — but phrase it as "not searched by the Kepler pipeline; KBONUS catalogue flags X; no KOI/TCE on this KIC", not "never searched" (Barber 2022 did).
**Tmag 12 TESS M dwarf**: SG1-class photometry of a >= 1,000 ppm event with a 0.4-1 m telescope is routine; speckle/AO contrast curves routine (and often already on ExoFOP if it is a TOI); recon spectra with 1.5-4 m telescopes; precise RVs feasible on CARMENES/MAROON-X/ESPRESSO/HPF/SPIRou-class instruments; validation and even confirmation are realistic *with* collaborators; without a TOI, the candidate must be published first before ExoFOP will host it.

## 8. The automated checklist for the Claude Code agent (run on every candidate, in order, with fixed thresholds written down before the search)

Each step writes a JSON record {test, inputs, statistic, threshold, pass|fail|inconclusive, code hash, timestamp} to `vetting/<candidate>/decision_log.jsonl`; nothing is deleted, thresholds are never edited after the first candidate is seen (Chopra: "post-hoc hold-out adjustments"; Kuber: the 12.5-14.5 d exclusion and the 26.7/15.5 thresholds were "chosen after inspecting results and cannot be presented as an independent validation").

**Stage 0 — pre-registration (before any light curve is opened).** Freeze: target list and ranking rule (hash the list), detrending method and windows, search band, number of peaks, first-screen thresholds (e.g. BLS/TLS SDE and SNR, >= 3 events in *each* subset, hold-out SNR, odd/even < 3 sigma, secondary < 3 sigma, max single-event contribution < 0.5), hold-out rule (Kuber: last max(2, ceil(0.25 N)) usable quarters/sectors; Chopra: hide a season), control runs (inverted f -> 2−f on every star; scrambled/shuffled seasons; injection-recovery on a random 5-10 % subsample), and the stopping rule. Record in `PREREG.md` with a git tag.

**Stage 1 — detection sanity (automatic, flux only).** Pass if: SDE/SNR above the frozen threshold using an *empirical* noise estimate (same box at >= 40 random off-transit phases; Chopra reduced red-flag misfires from 15-25 % to 5 % this way); >= 3 good events in the discovery set and >= 2 in the hold-out; hold-out depth consistent with discovery depth within 2 sigma at the *frozen* ephemeris (no re-search); inverted light curve does not reach the same SDE; not within 2 % of the TESS orbit multiples or Kepler 3-d desat harmonics unless pixel tests pass; events do not coincide with quality-flagged cadences (bitmasks in Section 5).

**Stage 2 — LEO-Vetter flux-level (tool: `leo_vetter` 1.2.0; ~2 s).** Run on the detrended + raw light curve with the catalogue star; pass = no FA flag and no FP flag with the default thresholds; log every metric; also run on the inverted light curve and at P/2 and 2P as controls. If LEO is not applicable (e.g. period > TESS limits), run exovetter ModShift/OddEven/Sweet/Lpp as the fallback.

**Stage 3 — shape and physics.** Fit with batman/emcee or TLS: report Rp/R*, b, a/R*, T14/T23; derived stellar density within 3 sigma of the catalogue (Gaia/TIC) density (Kuber: 4.4 (+2.3 −2.8) vs ~5 rho_sun); V-shape Rp/R* + b < 1.04 (flag) / < 1.5 (fail); Rp < 22 R_E (fail) and note < 8 R_E for TRICERATOPS thresholds; depth consistent across quarters/sectors/apertures (chi2 of per-season depths vs constant; for KBONUS, fit the dilution model with FLFRCSAP/CROWDSAP as Kuber did); detrending robustness (3 windows × 2 methods, transit masked) — depth changes < 1 sigma.

**Stage 4 — ephemeris match and catalogue novelty (tool: `scripts/novelty_check.py`).** Query KOI cumulative, DR25 TCE, TOI (TAP box), ExoFOP TOI+CTOI CSVs, pscomppars, k2pandc, Villanova + VizieR EB catalogues, Kostov 2025, Gaia vari/NSS, SIMBAD/VizieR within >= 10' (1° for Kp < 10 parents) plus every object on the same CCD channel/column (RaDex2Pix or TPF headers); compute Coughlin 2014 sigma_P/sigma_T for ratios up to 50:1; fail if any match (sigma_P >= 3.5 and sigma_T >= 2.0) to a *deeper* object that satisfies a spatial criterion; record "no match as of <date>" otherwise. Also an ADS object/full-text search for all identifiers.

**Stage 5 — pixel level.** TESS: transit-diffImage + LEO pixel vetting on every sector with transits; pass if Δθ <= 15" with prfFitQuality >= 0.3 in >= 2 sectors, and eumemic's F-test does not reject the target at p < 0.001 while rejecting each capable neighbour; also require the sign-aware check (the inverted light curve does *not* localise). Kepler/KBONUS: (i) neighbours' own PSF light curves at the ephemeris must be consistent with 0 and inconsistent with the depth they would need; (ii) per-quarter SAP depth must follow the dilution model, not the contaminant model; (iii) raw-TPF flux-weighted centroid shifts must match the target prediction and reject neighbours at Δchi2 > ~25; (iv) depth vs aperture radius flat. Inconclusive is an allowed outcome at low SNR — report it, do not promote.

**Stage 6 — companion and host checks.** Gaia DR3: RUWE, AEN, ipd_frac_multi_peak, non_single_star, NSS and vari rows for the target and every star within the aperture (soft flag RUWE > 1.25, hard flag > 1.4 or any NSS/vari_eclipsing_binary row); TIC contamination ratio; ExoFOP imaging/spectroscopy/stellar-companion downloads; expected secondary-eclipse depth for a stellar companion vs measured phase-0.5 limit.

**Stage 7 — statistical FPP (tool: TRICERATOPS 1.1.0, `scripts/triceratops_offline.py` pattern or `target()` when MAST works).** Inputs: folded, per-event-baselined, dilution-corrected light curve (or `dilution_corrected=False`), one cadence, real neighbours within 10 px with `calc_depths`, Gaia-based field population, any contrast curves (ExoFOP or your own), MOLUSC `kept.csv` built with `--gaia --ruwe`; N = 1e6, >= 10 seeds; report mean ± spread of FPP and NFPP and the dominant scenario; thresholds: validated FPP < 0.015 & NFPP < 10^-3 (only if Rp < 8 R_E and imaging exists); likely planet FPP < 0.5 & NFPP < 10^-3; otherwise candidate. Record which scenarios were skipped (missing background file) — never report an FPP computed without the D/B scenarios as if it were complete.

**Stage 8 — survey-level honesty (the thing editors ask).** For the whole run: number of stars searched (not selected), the full table of first-screen passes for real *and* inverted light curves, scrambled-run passes, injection-recovery completeness vs depth/period, the false-alarm fraction as a function of SNR from the inverted sample (eumemic: 46 % below MES 10, 16 % at 10-12, 2 % above), and every candidate's disposition with the failing test named (Kuber's audit table of 31 real vs 32 inverted signals is the model). State explicitly that search statistics alone do not single the candidate out if the inverted run contains signals of equal strength.

**Stage 9 — reporting.** Call it a "planet candidate" with FPP x ± y; list the dominant FP scenario and the single observation that would move it; give ephemeris with propagated uncertainty (Kuber: the marginal period error alone accumulates to ~40 min by 2027) and the prediction for the next observable transits; publish code, data hashes and the decision log (Zenodo DOI, as Kuber did) before any announcement; check TOI/CTOI/KOI/EB tables again on the day of release.

**Blind-analysis practices distilled from Kuber, Chopra and eumemic**: hold-out seasons/quarters chosen *before* the search and never re-searched (only fixed-ephemeris tests); inverted *and* scrambled controls through the *full* pipeline including triage (Chopra's first inverted test "searched for only one signal and skipped triage"); fixed, pre-written thresholds; decision log with code hashes; empirical noise from off-transit boxes; injection-recovery on the same detrending; report both versions when a test is changed; never rank targets by detectability alone (Chopra's top "never-2-min" stars had contamination ratios 68-222 — they were faint companions of bright stars); never claim "never searched by SPOC/Kepler" without checking the TCE tables and the literature; propagate timing (Chopra's UTC error of 6.5 min; QLP S99-104 barycentric bug); independent re-derivation by a second agent with its own code (Kuber's `independent_check/` reproduced the numbers but found the depth is method-dependent, 1,830-2,430 ppm).
